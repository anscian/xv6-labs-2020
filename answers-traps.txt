To get the same output, we need to reverse each byte of i which will in turn read same bytes in order in a big-endian machine. So, i = 0x726c6400 would do. As 57616 is printed with %x format specifier, there is no need to change it as in hex, it would be printed same in both little-endian and big-endian.
