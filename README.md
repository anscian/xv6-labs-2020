# xv6-labs-2020

This repository contains my solutions to the **xv6-labs-2020** operating systems labs.

The labs are based on the MIT operating systems course and are designed to provide hands-on experience with core OS concepts by extending the xv6 teaching operating system. The implementations in this repository represent my solutions and learning throughout the lab exercises.

## Contents

The repository includes solutions for various xv6 labs covering topics such as:

* System calls
* Page tables and virtual memory
* Traps and interrupts
* Copy-on-write
* Lazy allocation
* File systems
* Networking
* Locking and concurrency
* Multithreading
* Other kernel extensions

## Purpose

This repository serves as a record of my work while studying operating systems and implementing the xv6 lab assignments. The focus is on understanding kernel internals, memory management, process management, synchronization, and other fundamental OS concepts through practical implementation.

## Note

This repository is intended for educational purposes.
